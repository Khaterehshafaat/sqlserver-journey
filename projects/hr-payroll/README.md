# HR Payroll SQL Project

This project is part of my SQL Server learning journey and demonstrates practical SQL skills using a Human Resources and Payroll database.

## Objectives

- Practice SQL fundamentals
- Write clean and readable SQL queries
- Solve real-world HR and Payroll business problems
- Apply different SQL techniques, including JOINs, Subqueries, and Common Table Expressions (CTEs)

## Project Structure

| File | Description |
|------|-------------|
| `schema.sql` | Database schema, tables, constraints, and sample data |
| `beginner-queries.sql` | Basic SQL exercises (SELECT, WHERE, ORDER BY, GROUP BY, etc.) |
| `intermediate-queries.sql` | Intermediate SQL problems using JOINs, aggregate functions, and set operators |
| `advanced-queries.sql` | Advanced SQL solutions using Subqueries, CTEs, and other advanced concepts |

## Technologies

- Microsoft SQL Server
- T-SQL
