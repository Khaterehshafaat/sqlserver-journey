# 🚀 SQL Server Querying & Analytics Journey

Welcome to my comprehensive T-SQL learning repository! This project contains my complete SQL Server course materials, structured query exercises, and a full-scale HR & Payroll database case study.

## 📌 Repository Overview

The repository is structured into two main sections:
1. **Fundamentals (`/fundamentals`)**: Step-by-step T-SQL querying concepts, starting from basic `SELECT` queries to advanced `Recursive CTEs` and `Set Operators`.
2. **Projects (`/projects`)**: Practical, real-world database analytics scenarios. Includes a 50-question HR & Payroll case study solved via multiple SQL approaches.

---

## 📂 Modules & Contents

### 🗄️ Database Setup (`/database`)
- `TehranDataDB.sql`: Complete DDL/DML script for setting up the practice database environment.

### 📘 Course Fundamentals (`/fundamentals`)
- **01. SELECT & Aliases**: Basic syntax, schema notation, identifier rules, and aliases.
- **02. WHERE & Operators**: Filtering using comparison/logical operators, `IN`, `BETWEEN`, and `LIKE`.
- **03. Sorting & Pagination**: Sorting with `ORDER BY`, removing duplicates (`DISTINCT`), and pagination with `TOP` & `OFFSET-FETCH`.
- **04. NULLs & 3VL**: Three-Valued Logic, `IS NULL`, `IS NOT NULL`, and `ISNULL()` fallback.
- **05. Grouping & Aggregations**: Aggregation functions (`COUNT`, `SUM`, `AVG`), `GROUP BY`, and `HAVING` vs `WHERE`.
- **06. CASE Expressions**: Simple & Searched `CASE`, conditional logic, and custom NULL sorting.
- **07. String Functions**: Text manipulation via `LEN`, `DATALENGTH`, `SUBSTRING`, `CHARINDEX`, `REPLACE`, `STUFF`, and `CONCAT`.
- **08. Date/Time & Conversions**: Data type casting (`CAST`, `CONVERT`), `DATEADD`, `DATEDIFF`, and `DATEPART`.
- **09. CROSS & SELF Joins**: Cartesian products, table aliasing, and recursive self-referencing joins.
- **10. INNER & OUTER Joins**: Multi-table relational joins (`INNER`, `LEFT`, `RIGHT`, `FULL`), Non-Equi, and Composite joins.
- **11. Subqueries (Scalar & Multi-Valued)**: Self-contained scalar/multi-valued subqueries, handling `IN` and `NOT IN`.
- **12. Correlated Subqueries & EXISTS**: Inner query execution per outer row, `EXISTS`, and `NOT EXISTS`.
- **13. Derived Tables**: Table expressions, nesting, and the Three Guiding Rules.
- **14. CTEs & Recursive CTEs**: Non-recursive CTEs, multiple CTEs, and recursive hierarchy traversal.
- **15. Set Operators**: Combining result sets via `UNION`, `UNION ALL`, `INTERSECT`, and `EXCEPT`.
